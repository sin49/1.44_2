# 1.44_2


프로젝트 개요
-------------
**1.44MB Multi-Arcade**는 C++ 및 Direct2D 기반으로 제작된 릴레이 아케이드 게임 통합 프레임워크입니다. 
개별적으로 제작한 5개의 레트로 아케이드 미니게임(서바이벌, 오토배틀, 점프, 슈팅 등)을 하나의 클라이언트에서 연속적으로 플레이할 수 있도록 되어 있습니다.
